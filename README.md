# A3 – Superhot VR (Assessment 3)

Meta Quest 2 VR game (Unity 6, XR Interaction Toolkit). Extends the A2 prototype: [A2-Superhot](https://github.com/umed-khasanov/A2-Superhot).

## Status
Work in progress – started from the A2 project.

## Requirements
Unity 6000.3.22f1, XR Interaction Toolkit 3.3.2, XR Hands 1.9.0, OpenXR, Meta Quest 2.

## How to run
Open this folder in Unity Hub, open the scene in `Assets/A2/`, press Play (Meta XR Simulator) or Build And Run to Quest 2.
